# 打印机支持与验收

首台验收设备的品牌、型号、固件和连接方式待确认。切片配置的适用范围由设备、固件版本、喷嘴和材料共同决定。

| 通道 | 当前可执行的检查 | 真机验收条件 |
|---|---|---|
| OctoPrint 局域网 | 只读查询服务、设备状态、温度和可用的任务进度。已用本机样例响应测试。 | 指定 OctoPrint 服务地址，确认设备连通、权限和打印机配置 |
| Klipper / Moonraker 局域网 | 只读查询固件状态、打印状态、温度、层数和进度。已用本机样例响应测试。 | 指定 Moonraker 服务地址，确认设备连通、权限和打印机配置 |
| PrusaLink 和其他局域网 | 接入待机型选择。 | 官方接口、可用权限与实测固件 |
| 蓝牙 BLE | 接入待机型选择。 | 可核实的 GATT 服务、文件传输和控制协议、支持的浏览器及真机 |
| 厂商云 | 接入待厂商与授权方案。 | 官方设备授权、下发及任务状态接口、可验证机型 |
| 文件导出 | 本机工作台可从三种输入导出 STL、GLB 和离线刀路，文字 CAD 同时导出 STEP。 | 按目标机型重新切片并核对固件、喷嘴和耗材，再用实际设备验收 |

取得首台设备资料后，先只读复核状态。打印验收还需要合适的机型工艺配置、明确用户确认、设备返回接收和开始状态，以及实际完工记录。最终应把上传、启动、暂停、恢复、取消和断网状态分别记录。G0 没有执行物理打印。
